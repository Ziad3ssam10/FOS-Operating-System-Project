## Brief
FOS – Operating System Project is a small educational operating system built as part of the FOS course, focusing on low-level OS concepts such as booting, memory management, paging, page replacement algorithms, user environments, and simple user-level programs. 

## Features
- 32-bit x86 protected-mode kernel using GCC and binutils toolchain.
- Multistage boot process with support for emulators such as Bochs or QEMU.
- Physical and virtual memory management, including page directories, page tables, and page-fault handling with several page replacement policies (e.g., FIFO, CLOCK, WSClock depending on the assignment). 
- Basic user environments and system call interface for running simple user-space programs. 
- Organized source layout compatible with Eclipse CDT for convenient development on Windows and Linux.
